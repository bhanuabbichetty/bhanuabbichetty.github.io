# Publish Portfolio on GitHub Pages

1. Create a public repository named `bhanuabbichetty.github.io`.
2. Upload `index.html` from this folder to the repository root.
3. Upload your PDF in the same root with this exact file name:
   - `Bhanu_Portfolio.pdf`
4. Open repository settings:
   - `Settings -> Pages -> Deploy from branch`
   - Branch: `main`, Folder: `/ (root)`
5. Wait 1-3 minutes and open:
   - `https://bhanuabbichetty.github.io/`

If the old `/portfolio` URL still appears in browser history, use the root URL above.
